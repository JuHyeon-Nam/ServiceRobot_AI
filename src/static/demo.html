5분 시연 흐름

졸업작품 전시나 리뷰 상황에서 설명 순서를 고정해두면 완성도가 안정적으로 보입니다.

시연 순서

  1. /demo에서 전체 구성과 완성도를 먼저 보여준다.
  2. /twin에서 AGV 이동, 경고 색상, 설비 선택 패널을 보여준다.
  3. /api/phm으로 PHM 단계, 위험도, RUL 추정, 조치 권고를 확인한다.
  4. /api/work-orders로 AI 경고가 정비 작업지시로 연결되는 것을 확인한다.
  5. /api/tsdb-export?fmt=influx로 외부 시계열 DB 적재 포맷을 보여준다.
  6. /api/ops-report?fmt=md로 운영 보고서 export를 보여준다.
  7. /api/drift, /api/model-card, /metrics로 AI 운영 품질을 증명한다.

남은 마감 작업

  • 2-3분 구현 영상 캡처 및 README 상단 연결.
  • 실제 MQTT broker bridge와 외부 시계열 DB profile 추가.
  • 실물 센서 또는 MQTT-fed replay 입력으로 물리 데이터 현실성 보강.
